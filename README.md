This project focuses on solving the Traveling Salesman Problem (TSP) by implementing and evaluating multiple algorithmic approaches.
It includes a variety of datasets and aims to find optimal or near-optimal tour paths using the C# programming language.
The goal is to balance both performance and solution quality for different problem sizes.

Algorithm	                  Description
Nearest Neighbor	    :     Fast initial solution using a greedy heuristic
2-Opt	                :     Local optimization for shorter route improvements
Genetic Algorithm     :   	Evolutionary approach with population-based search
Simulated Annealing   : 	  Probabilistic acceptance to escape local minima
K-Means + Greedy      : 	  Pre-clustering for faster computation on large datasets
